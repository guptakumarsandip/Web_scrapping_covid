# 🦠 COVID-19 Data Scraper & Visualizer

## 📖 Overview
This project is a Python-based data pipeline that scrapes real-time COVID-19 statistics from [Worldometers](https://www.worldometers.info/coronavirus/), cleans and processes the data, and generates interactive visualizations. 

## ✨ Features
*   🕸️ **Web Scraping:** Extracts live HTML table data using `BeautifulSoup` and `requests`.
*   🧹 **Data Cleaning:** Cleans up text elements, removes commas from numeric strings, and handles structural HTML parsing using `lxml`.
*   💾 **Data Storage:** Automatically exports the parsed data into a neat `covid_data.csv` file.
*   📊 **Data Visualization:** Utilizes `pandas` for data manipulation and `plotly` to render interactive Bar and Pie charts representing the Top 10 countries by total cases.

## 🛠️ Prerequisites
To run this notebook, you will need Python installed along with the following libraries:
```bash
pip install beautifulsoup4 requests lxml pandas chardet plotly
```

## 🚀 Usage
1. Clone this repository or download the Jupyter Notebook.
2. Install the required dependencies listed above.
3. Run all the cells in the notebook sequentially.
4. The script will automatically scrape the latest data, save it to `covid_data.csv`, and display the interactive charts directly in your notebook environment.

## 🗂️ Project Structure
*   `notebook.ipynb`: The main Jupyter Notebook containing the scraping and visualization code.
*   `covid_data.csv`: The output data file generated by the script.
